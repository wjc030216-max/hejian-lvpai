# 二期流程设计：按老板 20261004 参考图调整

状态：2026-10-08 首页进一步改为沉浸式自动播放。此稿替代此前“先选景区、再进入热门模板”的入口设计。付款为开发跳过；抽奖功能已移除。

## 主流程

打开小程序 → 全屏模板首页（浏览与筛选同页完成）→ 按模板角色上传照片并付款 → 本次作品（自动生成定妆照、自动生成视频）。

支付仍保留当前用户要求：本地开发直接跳过实际付款。所有生成服务、存储与生产隔离的约束继续生效。

## 模板首页

- 取消独立的景区选择首页、热门模板中转页。打开即有模板画面，不能先经过空白问卷。
- 视频作为首页主背景，顶部“全部景区/当前景区”和“筛选”按钮打开同页面板，不要求先选景区。当前实际景区为漓江和银子岩；参考图“两江四湖”不是新增景区授权。
- 采用深色背景、金色动作按钮。打开即自动静音播放当前模板，上下滑动切换并自动播放下一款；点画面暂停/播放，右下角开关声音。只挂载当前视频，离开页面或打开面板停止，返回或关闭面板恢复播放。竖屏使用 contain 保留完整比例，导航与动作悬浮呈现，并预留系统安全区域。
- 名称取 video_name，宣传语取 story_hook。模板示例需明确标识，不能混淆为已生成的游客作品。
- 右侧直接进入作品。按参考布局取消原五项底部导航；“我的”入口已随抽奖权益页删除，作品功能保留在作品页，不再单独增加入口。
- 底部“帮我选”展开参考图的逐步筛选：人数 → 推荐性别 → 年龄 → 同行关系。始终在当前页面切换面板，支持上一步、跳过及修改已选项。
- 允许直接浏览模板并点击拍摄。已选定具体模板后不再强制重复回答人数、关系。
- 只有存在可靠模板字段时才展示筛选项。人数来自 actor_count，关系来自 relationship_tags，类型来自 video_genre；推荐性别与年龄读取 module_2.recommendation_persona 中的 recommended_gender / recommended_age；不限的模板保留匹配，不从名称猜测。
- 人数是模板匹配条件，不是改变模板角色数量。选择三人只能推荐真实三人模板，不向双人模板临时插入孩子。
- 不设主角。模板有几个角色，就显示几个坑位；人数筛选表示成片同框人数，不是游客实际人数。
- 推荐首批少量模板，分批加载，避免把 500 多条视频同时放进页面。只播放当前模板，预取下一页；保留换一批、筛选、更多模板入口，更多模板用同页抽屉浏览。
- 没有匹配模板时展示空状态，提供撤销最近筛选/清除筛选，不能偷偷展示不符人数的模板或编造热度。

## 上传并付款

- 按 character_settings 生成照片槽位，标题使用真实角色名称；不固定写“主角、同行者、孩子”。例如当前三人模板使用孩子、父亲、母亲。
- 一人、两人、三人使用对应布局。多人模板支持“一人体验”：明确选择一个游客坑位，其余使用对应模板人物；切换模式保留草稿照片，只有参与制作的游客照片需要检查通过。详见 PHASE2_SINGLE_EXPERIENCE.md。
- 照片授权在上传并发起检查之前告知和取得；付款处确认生成服务说明。文案中的照片用途、保存与删除承诺必须与实际实现一致。
- 顶部保留当前模板概要，支持返回修改且保留原模板已上传照片。更换模板时按稳定角色编号核对，不按卡片位置盲目复用。
- 产出固定展示“一张定妆照 + 一段视频”。价格未配置不显示虚构金额，本地按钮明确“跳过付款并开始制作”。

## 作品

- 本次作品左侧定妆照、右侧视频，均为完整竖屏卡片。小屏允许纵向滚动，底部固定按钮预留空间。
- 定妆照保存后立即可见、可下载，后台自动继续视频。定妆照仅展示与存储，不传视频模型；视频继续使用原始人物照片、角色造型和模板场景资料。
- “再次拍摄”返回首页，保留浏览位置与筛选；旧制作任务独立继续，不覆盖旧作品。
- 视频失败仍保留已完成定妆照。本地显示未扣款；真实退款未接入时禁止显示“已发起原路退款”。
- 生成完成提醒先使用站内作品标记；微信订阅通知另行接入并经游客订阅后，才能承诺离开小程序仍收到提醒。

## 前后端改动边界

首页合并浏览、筛选、推荐与播放状态；去掉旧景区中转和重复确认入口。上传、作品沿用现有二期接口并调整呈现。后端新增推荐分页及可靠的筛选字段校验；不改变已确认的自动制作、制作快照、独立角色绑定、作品保存、幂等订单和本地隔离规则。
