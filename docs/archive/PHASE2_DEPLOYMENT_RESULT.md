# 二期三机测试交付结果（2026-10-08）

## 已交付

- 主节点：二期游客接口、模板目录与固定快照、微信身份校验、HTTPS 入口、管理员入口转发。
- AI 节点：阿里云人脸检测、Seedream 定妆照、Seedance 视频、持久任务进度和中断恢复。定妆照作为用户资产保存，不传入视频模型。
- 管理与数据节点：管理员登录、模板 ZIP 上传和校验、上下架、样片预览、展示热度、制作记录、操作日志、服务连通和管理节点磁盘监控；MySQL、Redis、文件和 TOS 服务。
- 小程序：上下滑动竖屏样片，景区和标签筛选，按模板角色上传，一人体验，测试付款跳过，制作进度和作品。前端仍在 Windows 微信开发者工具使用。
- 一期旧页面、支付、抽奖、分镜及旧服务启动逻辑已移出运行代码。抽奖数据库定义仅保留注释；未删除已有数据库或本地数据卷。

展示热度 = 管理员填写的基数 + 实际确认制作人数。同一游客对同一模板只计一次；真实统计不包含填写的基数。上传模板默认下架，替换后保留旧素材供已开始的制作使用。

## 性能与监控边界

三机部署先限制定妆照、视频各并发 1 个；日志限制大小，模板目录缓存 15 秒，作品分页，生成步骤持久保存。500 多条模板本身不需要拆数据库，优先压缩封面和手机预览样片，再根据同时观看人数评估对象存储和内容分发。

后台提供业务日志、服务连通和管理节点磁盘数据，不包含全机 CPU/内存、云账号余额或所有容器堆栈。完整报错用部署说明中的日志命令查看。批量导入真实模板后应另做并发浏览、上传和生成排队测试，不能用三条样例推算线上容量。

上传文件、服务器地址、目录、配置和启动命令见 [三台服务器部署说明](DEPLOY_THREE_SERVERS.md)。
