# 二期模板资产与传输约定（原型版）

截图中的一套模板资产按以下语义使用：

| 资产 | 游客端呈现 | 生产端用途 |
| --- | --- | --- |
| 基础元数据 | 片名、故事、人数、时长、价格、标签 | 筛选与订单快照 |
| 场景设定图 | 场景预览、拍摄氛围 | 定妆照与视频场景参考 |
| 角色设定图 | 角色卡、人物位置说明 | 角色外形和构图参考 |
| 服装图 | 角色造型卡 | 定妆照、三视图参考 |
| 道具图 | 道具点缀说明 | 定妆照参考 |
| 分镜图 | 模板示范中的镜头预告 | 视频镜头调度参考 |
| 成片案例 | 模板详情播放 | 游客了解最终效果 |
| 定妆照提示词 | 不直接展示，只显示生成说明 | 定妆照生成 |
| 分镜/视频提示词 | 不直接展示 | 视频生成 |

原型中的 `templateAssets.roles[].slotId` 是角色绑定的关键。用户照片必须绑定 `slotId`，不能用数组下标或上传先后顺序判断角色。

正式接口建议只向游客返回展示字段；支付时由服务端保存模板版本、角色槽位、资产版本、提示词版本和价格快照，后台任务再根据快照取生产资产。
