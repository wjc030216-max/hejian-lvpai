# 本地验收与下一步（2026-10-08）

## 现在运行
在 PowerShell：
    cd G:\桂智旅\aitravel\aitravel
    .\start-local-real.ps1 -CheckOnly
    .\start-local-real.ps1 -NoBuild

保留素材隧道窗口。若 HTTPS 隧道地址失效，用 .\start-local-tunnel.ps1 开新隧道并更新 .env.local.real 的 LOCAL_PUBLIC_BASE_URL。
启动脚本先关闭云端调用、检查本机素材通路，再启用真实调用。
当前本机镜像已经更新，可用 -NoBuild 启动。以后修改后端源码须重新构建对应镜像；不带 -NoBuild 的命令会构建全部服务。前端源码保存后在开发者工具重新运行即可。

微信开发者工具使用当前 client 目录，或打开根目录项目（miniprogramRoot 为 client/）。
业务地址固定 http://127.0.0.1:8080。不需要上传测试服务器，也不要上传发布到线上小程序。

## 验收顺序
1. 打开即看到模板首页；上下滑动、点击播放、切换景区筛选、帮我选、更多模板、换一批均在同页完成。点“拍摄同款”。
2. 多人同框需上传全部角色照片；一人体验先选“我演这个”，只上传选中角色照片，其余使用模板人物。检查中不能付款，失败可更换。
3. 上传前确认照片授权；本次参与制作的游客照片检查通过后勾选制作说明，点“跳过付款并开始制作”。微信不扣款，云 API 仍按调用计费。
4. 进入作品查看进度。定妆照出现后后台自动生成视频，两种资产均竖屏展示。
5. 制作中可离开页面或另拍一部，作品页可返回每一份记录。
6. 旧定妆照显示为历史测试作品，不会自动补发视频。
