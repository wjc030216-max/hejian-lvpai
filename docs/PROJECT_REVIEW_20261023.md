## 2. 本轮修复

| 项目 | 处理结果 |
|---|---|
| 管理台媒体加载 | 最终定妆照和最终视频统一使用同源 `download=1` 流，避免 CSP 拦截 TOS 302 重定向 |
| 视频预览带宽 | 同源媒体流转发 `Range`，返回 `206/Content-Range`，管理台只读取所需片段 |
| 日志隐私 | 中央日志在上报、落盘、写库和管理台展示前统一移除媒体路径安装令牌、签名参数及 Bearer 令牌 |
| 管理台健康检查 | Compose 显式注入 main/AI/file/TOS 地址，正式环境不再回退到测试内网 IP |
| 作品状态轮询 | 新增轻量 `/api/v2/works/watch` 查询，只读取状态、媒体布尔值和视频名，不再每 15 秒读取最多 100 条完整项目 JSON |
| 构建速度 | 发布版本和构建时间标签移到依赖安装之后，代码更新不再强制重装 pip 和 ffmpeg |
| 模板仓库 | 仓库只保留模板管理代码，不保留 `templates.json`、测试模板目录或部署模板包；模板由管理员后台上传 |
| 生成并发 | Seedream/角色生成按 500、视频按 40；视频云端在途上限 40 |
| 视频模型 | 默认模型为 `doubao-seedance-2-0-fast-260128` |
| 媒体编码 | 实际成片为 H.264 High、`yuv420p`、720×1280、15.04 秒，浏览器可解码 |

主要代码位置：

- `server/admin/static/app.js`：管理台媒体同源流和失败恢复。
- `server/phase2/phase2_app.py`：媒体 Range 流和轻量状态接口。
- `server/phase2/store.py`、`server/phase2/mysql_store.py`：SQLite/MySQL 轻量状态查询。
- `server/common/redaction.py`：统一日志脱敏。
- `infra/staging/docker-compose.data.yml`：管理台跨节点健康检查配置。

## 5. 仍需运维确认的边界

以下不是本轮代码阻断项，但上线前或运营中必须用真实环境指标确认：

1. 5000 日活、100 瞬时并发是当前设计目标。本次仅用 100 并发访问健康检查和模板目录做了 200 次只读烟测，全部成功且 p95 小于 2 秒；这不代表 AI 长任务、上传、TOS 大文件和云厂商配额也已完成同等级压测。正式大促前仍需监控 MySQL 连接池等待、任务队列最老等待时间、main 出口带宽、TOS 域名限制和火山账号配额。
2. main 网关、MySQL 和 Redis 仍是单点，当前三节点用于职责隔离，不是数据库高可用架构。
3. 云厂商余额、并发配额、模型权限和内容审核政策无法仅通过代码测试确认。
4. 微信支付回调按本次指令保持不变，因此不纳入本轮修复验收。
5. 真实支付、退款、生图和视频提交未在本次回归中触发，测试全部使用 mock 或既有真实成片只读验证。
